# Job Quest — Demo MVP

Try a job before you choose a job.  
This MVP lets users pick a quest (mini job task), submit work, and get graded by a mentor.

**Stack**

- Next.js 15 (App Router) + TypeScript + Tailwind
- Supabase (Auth + Postgres + RLS)
- Vercel (hosting)

---

## Quick Start

### 1) Clone & install

```bash
git clone https://github.com/Sepii84/job-quest-demo.git
cd job-quest-demo
npm install
```
